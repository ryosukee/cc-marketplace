# 残量を 1 行で出す

コンテキスト残量と 5 時間枠・週枠の残量を 1 行で出す。

## 実行

```bash
"${CLAUDE_PLUGIN_ROOT}/scripts/render-usage-line.sh"
```

出力例:

```text
ctx 30% | 5h 87% 残17m→13:50 | 週 19% 残5h 27m→7/27 19:00 | 今日 6/25pp
```

すべて残量。`ctx` はこのセッションのコンテキスト、`5h` と `週` はアカウント全体のレート制限、
`今日` は「今日の消費 / 1 日あたり予算」を percentage point で示す。

## 出力をそのまま返す

整形し直さない。数値を文章に開かない。1 行のまま返す。

## 失敗したとき

| exit code | 意味 | 返し方 |
| --- | --- | --- |
| 1 | このセッションの JSON が無い | 「残量データがありません」と伝え、セットアップ状況を確認するか尋ねる |
| 2 | `jq` 不在、または session_id を特定できない | stderr の内容をそのまま伝える |

推測で値を埋めない。取得できなかったことを伝える。

## 前提

statusline が JSON を書き出していること。書き出しが無いと動かない。
セットアップは plugin の README を参照。

Remote Control のセッションでのみ動く。クラウドセッションには書き出し元が存在しない。
