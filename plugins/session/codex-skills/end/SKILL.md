# セッションを終了する

この SKILL.md の所在から二階層上の plugin root を特定する。
`references/end.md` を読み、記載された手順に従う。
各工程は同じ `codex-skills/` の `debrief/SKILL.md`、`retrospective/SKILL.md`、
`handover/SKILL.md` を順に読んで実行する。次回の開始方法は `start` skill と案内する。
`end.md` を読めない場合は、セッション終了を完了したと報告しない。
