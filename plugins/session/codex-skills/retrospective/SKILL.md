# セッションを振り返る

この SKILL.md の所在から二階層上の plugin root を特定する。
`references/retrospective.md` を読み、記載された手順に従う。
そこから指定される `draft-tasks.md` も plugin root の `references/` から読む。

候補の件数にかかわらず、一件ずつテキストで対話する。
`retrospective.md` を読めない場合は、振り返りを完了したと報告しない。
