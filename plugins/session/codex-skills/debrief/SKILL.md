# セッションを棚卸しする

この SKILL.md の所在から二階層上の plugin root を特定する。
`references/debrief.md` を読み、記載された手順に従う。
そこから指定される資料も plugin root の `references/` から読む。
`debrief.md` を読めない場合は、棚卸しを完了したと報告しない。
