# debrief

`${CLAUDE_PLUGIN_ROOT}/references/debrief.md` を Read し、記載された手順に従う。
そこから指定される資料も `${CLAUDE_PLUGIN_ROOT}/references/` から読む。
`debrief.md` を読めない場合は、棚卸しを完了したと報告しない。
