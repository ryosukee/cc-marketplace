# 日本語の曖昧さ 3 分類 8 型

この 3 つは、読み手が文を読んでも何のことか決められない状態を作る。
どれも書き手の側では気づきにくい。書き手は指すものを知っているので、
省いても自分では読める。

## I 指すものが文の中で決まらない

### I-1 造語と汎用語

汎用語を特定の物の名前として使わない。対象は「台帳」「一覧」「設定」「エントリ」「軸」「条項」
「明細」「面」「形」「向き」「層」「枠」「観点」「粒度」「論点」のような語。
文脈を共有していない読み手には、どれを指すか決まらない。

特定のファイル・エントリ・plugin を指すときは、固有名（ファイル名・plugin 名・エントリの id）で呼ぶ。
定義を添えても足りない。同じ語が同じ文書の中で別の物も指しうる。

その場で付けた呼び名も同じ。数と汎用名詞の組（「3 項目」「上の 4 点」「層 0」）、頭文字や省略形、
その場で振った番号や記号（「A 案」「B-C」「0-A」「2-b」）が対象。
使ってよいのは、中身が直前か直後に書いてある場面だけ。離れた箇所や別の文書から指すときは、
何を指しているかを書く。番号や記号だけで指してよいのは、課題管理の番号のように
プロジェクトで共有された慣習があるものだけ。

「軸」は特に混ざる。グラフの横軸・縦軸や回転軸を指すときだけ使い、
比較の観点なら「比較基準」「比較項目」、測定の内容なら「評価方法」「評価指標」「測定対象」、
複数の性質なら「性能要素」「変数」を使う。

判定基準: その語を、読み手が固有名か実物へ置き換えられるか。

用例。「作業対象のプロジェクトに既にある作り方」と書くべきところを「対象の既存パターン」と書いた。
「調査・概算・資料作成の担い手」と書くべきところを「実行主体」と書いた。

### I-2 指示語だけの接続

話題が変わるときに「ここで」「この軸」「この事例」「この結果」「両者」のような指示語だけで繋がない。
指示対象を名詞で言い直す。段落が変わったときは、最初の文で何の話かが分かるようにする。
「効果」「この結果」「同様に」のような、複数の物を指しうる語から段落を始めない。

判定基準: その指示語を、直前の名詞で置き換えて文が成立するか。

### I-3 主題の欠如

その文が何についての文かを、文の中で共有していない状態。日本語は主語を省けるが、主題は省けない。
「象は鼻が長い」の「象は」が主題で、これが無いと「鼻が長い」は誰の鼻の話か決まらない。

判定基準: その文だけを取り出したとき、何についての文かが分かるか。
分からないなら、主題を文の中に書く。

用例。「同じ形が向きを変えて戻ってくる」は、何の形かを書いていない。
「`research-ledger.md` の判定が、この主語で反転する」は、何の主語かを書いていない。

見出しにも同じことが当たる。「分かったこと」「既知の弱点」のような、
何についての見出しか分からない見出しを付けない。

### I-4 曖昧な動詞

1 つの動詞が複数の操作をまとめているとき、その操作を表す動詞へ変える。
「置く」が掲載・説明・仮定・定義・作成のどれかをまとめているなら、
「計画シナリオを置く」は「仮定する」、「test を置く」は「用意する」と書く。

判定基準: その動詞を、実際に行う操作の名前へ置き換えられるか。

## II 主語と述語が実物と対応しない

### II-1 非生物主語

書き手・読み手・実行者がする動作を、モノや抽象名詞にさせない。

| 動作主が消えた形 | 動作主を戻した形 |
| --- | --- |
| フィールドが置き場の分からない情報の受け皿になる | 書き手は置き場に迷った情報を何でもそのフィールドへ入れる |
| データが示している | データを見るとこうなっている |
| 文化が醸成される | 経営陣が文化を作った |
| 課題が浮き彫りになる | やってみて課題に気づいた |
| 思想が結実する | 設計者がそう作った |
| 複雑性が増していく | 機能を足しすぎた |
| プロセスが定着する | みんながやるようになった |
| 議論が深まる | 話していたら細かい話まで出てきた |

非生物を主語にすること自体は禁じない。「結果が示す」「表が示す」は使える。
止めるのは擬人化と換喩で、事例が何かを「残す」、単位が「動く」、予算を「配る」のような形が対象。
これらは技術的な操作へ戻す。「区別が生きる」は「区別が有効である」、
「評価が動く」は「報告される評価指標が変わる」と書く。

判定基準: その文の動作主（誰が・何が）を 1 語で書き出せるか。
書き出せないなら、まだ何を言いたいかが決まっていない。決めてから書く。

### II-2 比喩

比喩には 3 つある。メタファー（隠喩）は別の領域の構造を写す。メトニミー（換喩）は
隣接するもので置き換える（ヤカンが沸く、霞が関が決めた）。シネクドキ（提喩）は全体と部分を入れ替える。

残してよいのは、分野で定着している比喩か、直後に技術的な意味を定義する比喩だけ。
その場で作った比喩を使ったときは、比喩が指す中身を同じ段落に書く。何が同じで何が違うかを書く。
書けないなら、その比較はまだ成立していない。

判定基準: その比喩を、分野の文献で他の書き手も使っているか。使っていないなら中身を書く。

用例。「同じ形が向きを変えて戻ってくる」はメタファーで、何が同じで何が逆かを書いていない。
「一方は名前が広すぎ、もう一方は狭すぎる。どちらも名前と中身が対応しない」と書く。

### II-3 名詞構文

動作を抽象名詞に変えて、動作主を落とす形。非生物主語とは逆向きの操作で、
非生物主語がモノに動作をさせるのに対し、名詞構文は動作をモノに変える。

「実行主体を揃える向きは、記載の無い GCP 調査に足す形を想定している」は、
「揃える」を「向き」に、「足す」を「形」に変えている。
「GCP 調査にも、誰が調査したかの 1 文を書く」と書く。

判定基準: 文の中の抽象名詞を、動詞へ戻せるか。戻せるなら戻す。

## III 修飾が積み上がって係り受けが決まらない

### III-1 連体修飾の積み上げ

日本語は連体修飾を名詞の前に置くので、修飾節を重ねると、どの修飾がどの名詞に係るかが決まらない。
英語の関係節をそのまま日本語へ移すとこの形になる。

「挙動を持たないフィールドが置き場の分からない情報の受け皿になる」は、主語が
「挙動を持たない」+「フィールド」、目的語相当が「置き場の分からない」+「情報」で、
修飾節が 2 つ積み上がっている。「書き手は置き場に迷った情報を何でもそのフィールドへ入れる」と書く。

判定基準: 主語か目的語に、連体修飾節が 2 つ以上入っているか。入っているなら文を分ける。
