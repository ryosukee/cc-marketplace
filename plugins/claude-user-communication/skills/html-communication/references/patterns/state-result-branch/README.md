# 状態図：操作結果による分岐

予約済みから通知送信の受理・拒否によって異なる状態へ移る関係を示す。

## 名前

状態図は公式の呼称。操作結果による分岐は、この見本の配置を説明するために付けた名称。

## 使ってよい条件

- 同じ開始状態・操作から、結果によって異なる状態へ進むとき
- 結果が択一で、どちらへ移るかを枝のラベルで示せるとき

## 使ってはいけない条件

- 同時に複数の状態が有効になるとき。その場合は state-parallel を使う
- 処理順だけを説明するとき。その場合は flowchart-decision を使う

## 近縁パターンとの区別

flowchart-decision は処理と判断を示す。この例は保持する状態をノードにし、操作と結果を経路へ置く。
