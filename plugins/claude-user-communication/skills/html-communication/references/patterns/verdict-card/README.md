# verdict card

検証や受入基準など、同型の項目を判定バッジ付きで並べる。
1 件 = カード 1 枚で、中身は定型の 3 行。

## 使ってよい条件

- 同型の項目が 3 件以上あり、それぞれに可否の判定が付くとき
- 1 件あたり 2〜4 行の説明が要るとき。表にすると 1 セルが文になって破綻する
- 判定の理由まで読ませたいとき

## 使ってはいけない条件

- 1 件あたりの説明が短い判定値だけのとき。表のほうが横比較できる
- 項目が 2 件以下のとき。地の文で足りる
- 判定が付かない一覧のとき。判定バッジが空振りする

## 近縁パターンとの区別

比較表（`table` + `tr.key`）と解決したい問題が重なる。分かれ目は 1 件あたりの分量で、
判定値だけなら表、説明が要るならカード。表は横比較に強く、カードは縦読みに強い。

## 注意

状態の class に `.ok` / `.ng` を使わない。雛形が `.ng { color: var(--ng) }` を持っており、
カードに付けると本文まで着色される。`.v-ok` / `.v-ng` を使う。

判定は色だけに載せない。バッジのテキストで読めるようにする（WCAG 1.4.1）。
色を載せるのは左の縦罫とバッジだけで、本文は無彩のままにする。
