# 状態図：循環

稼働中と一時停止中が別々のイベントで相互に切り替わる関係を示す。

## 名前

状態図は公式の呼称。循環は、異なる状態を往復する見本の配置を説明するために付けた名称。

## 使ってよい条件

- 異なる状態間に往路と復路があるとき
- 方向ごとに経路とイベント名を分けて示せるとき

## 使ってはいけない条件

- 一つの状態へ戻るだけの遷移を説明するとき。その場合は state-self-transition を使う
- 完了へ一方向に進む工程だけを説明するとき。その場合は vertical-progress-indicator を検討する

## 近縁パターンとの区別

state-self-transition は同一状態へ戻る。この例は異なる状態を往復し、上下の進行順を与えない。
