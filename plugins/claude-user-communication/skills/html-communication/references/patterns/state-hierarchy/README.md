# 状態図：階層

親状態の稼働中に属する待機と処理中を、親の枠内に示す。

## 名前

公式資料の composite states（複合状態）に対応する。階層は、この見本の親子関係を説明するために付けた名称。

## 使ってよい条件

- 子状態が有効である間、親状態も有効である関係を説明するとき
- 親の境界と子状態の遷移を分けて描けるとき

## 使ってはいけない条件

- 関連項目を単に囲むだけのとき。その場合は構成図や箇条書きを使う
- 独立した複数の状態軸が同時に有効になるとき。その場合は state-parallel を使う

## 近縁パターンとの区別

state-parallel は同時に有効な状態軸を分ける。この例は一つの親状態の中で待機・処理中が切り替わる。
