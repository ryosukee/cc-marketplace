# 状態図：自己遷移

通知失敗からの再送信が受理なら通知済みへ進み、拒否なら通知失敗へ戻る関係を示す。

## 名前

自己遷移を表す状態図。ディレクトリ名は、この関係の見本を区別するために付けた。

## 使ってよい条件

- イベントを実行しても同じ状態へ戻る経路があるとき
- 自己遷移の線とラベルを他の状態への遷移から分けて置けるとき

## 使ってはいけない条件

- 二つ以上の異なる状態を往復するとき。その場合は state-cycle を使う
- イベントを実行しなかったことを表したいとき。自己遷移はイベントが発生したことを表す

## 近縁パターンとの区別

state-cycle は異なる状態を往復する。この例は同じ状態へ戻る経路を外側に置く。
