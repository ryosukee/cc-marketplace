# item radio

同じ二択を複数の項目へ繰り返し、項目ごとに独立した判断を求める。
説明的に付けた名前であり、特定のデザインシステムの公式名称ではない。

## 使ってよい条件

- すべての項目が同じ二択を持ち、項目ごとに一つを選ぶとき
- 選択肢の文言が短く、項目数も少ないときは、各項目に選択肢の文言をそのまま表示する
- 選択肢の文言が長いとき、または項目数が多く同じ文言の反復が読みづらいときは、
  各選択肢を記号で表示する。記号と文言の対応は、最初の項目より前にある設問カードの冒頭で定義する
- 記号を使う場合も、項目名だけで各判断の対象が分かるとき

## 使ってはいけない条件

- 項目ごとに選択肢が異なるとき
- 一つの項目で複数の選択肢を同時に採れるとき
- 文言を繰り返しても読みづらくならないのに、短く見せる目的だけで記号へ置き換えるとき
- 記号の定義を省くとき、または定義を設問カードの外へ置くとき
- 関係のない複数の設問を、一つのカードへまとめるとき

## 近縁パターンとの区別

通常の radio は、設問全体から一つだけ選ぶ。item radio は、同じ二択を持つ項目ごとに一つずつ選ぶ。
checkbox は、同じ項目で複数を選べる場合に使う。
