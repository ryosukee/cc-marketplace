# 状態図：並行

動作中の通信と保存という状態軸が同時に有効であることを領域で分けて示す。

## 名前

公式資料の concurrency（並行状態）に対応する。ディレクトリ名は、この見本を区別するために付けた。

## 使ってよい条件

- 複数の状態軸が同時に有効で、軸ごとの状態を同時に示す必要があるとき
- 親状態の中に領域を分け、各領域の名前を付けられるとき

## 使ってはいけない条件

- 成功か失敗かなど、択一の結果を説明するとき。その場合は state-result-branch を使う
- 親の中で一つの子状態だけが有効になる関係を説明するとき。その場合は state-hierarchy を使う

## 近縁パターンとの区別

state-hierarchy は親の中で子状態が切り替わる。この例では通信の接続中と保存の未保存が同時に有効である。
