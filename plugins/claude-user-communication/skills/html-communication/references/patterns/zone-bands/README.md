# zone bands

所有・信頼の範囲を横帯で積み、帯ごとにアイコン・名前・その中の構成要素を並べる。
帯の間に矢印を置いて、何が渡るかを書く。

## 使ってよい条件

- 範囲が 2 つから 4 つで、上下の順序に意味があるとき（外から内、上流から下流）
- 範囲の中の構成要素が 1 件から 4 件で、名前だけで足りるとき
- 「どこからどこまでが誰のものか」が図の主題のとき

## 使ってはいけない条件

- 構成要素ごとに説明が要るとき。タグに収まらない。帯の中を入れ子のカードにするか、表へ移す
- 範囲の入れ子が 2 段以上あるとき。この形は 1 段しか表せない
- 範囲どうしの関係が上下 1 本で表せないとき。分岐や戻りがあるなら別の形が要る
- 範囲が 5 つを超えるとき。縦に伸びて 1 画面に収まらない

## 近縁パターンとの区別

表で「対象 × 担い手」を書く形と解決したい問題が重なる。分かれ目は順序で、
上下の並びそのものに意味があるならこの形、無いなら表のほうが読める。

## 注意

**色と余白の詰め方は暫定。** 3 層構成図の作例を参考に組んだもので、この repo の
見た目として決着していない。骨格（帯・アイコン・名前と副題の 2 段・タグ列・帯の間の矢印）は
残し、色の選び方と間隔は調整する前提で使う。

CSS は Tailwind の生成物で、`style.css` を手で編集しない。作り直す手順は
[パターン集の README](../README.md) の「図を Tailwind で組む」にある。
貼り込み先は生成ページの `<style data-scope="figures">`。

色に意味を載せているので凡例が要る。この例では帯の名前と副題がその役割を兼ねていて、
色だけで所有者を区別させていない。

> 情報源: 3 層構成図の作例（[図解作成、AI に丸投げしたら「たまに自分より上手い」件](https://tech-lab.sios.jp/archives/51249)）。
> 淡い塗りに同系色の 2px の枠、左に大きいアイコン、右にタグ列という組み合わせをここから取った。
