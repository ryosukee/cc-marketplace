# progress tree

入れ子の作業群（PR 群とその中身、工程とその作業項目）の進み具合を、
階層付きの一覧で示す。各項目は完了・現在・未着手の 3 状態を、マーカーの形と語の両方で持つ。

## 名前

自分で付けた。公式の呼称は無い。近い形は tree view（WAI-ARIA APG）と
チェックリストだが、どちらも進行の状態を表すコンポーネントではない。

## 使ってよい条件

- 作業が 2 階層以上に分かれ、上位の進み具合が下位の項目の状態で決まるとき
- 項目ごとに完了・現在・未着手の状態があるとき
- 上位の項目が直列でないとき（独立して進むものが混ざる、順序が任意）

## 使ってはいけない条件

- 1 階層で足りるとき。直列なら vertical progress indicator、直列でないなら箇条書きにする
- 状態を持たない構成の説明（ディレクトリ構成、文書の目次）。tree view か箇条書きにする
- 現在地が 1 つに定まる直列の工程。vertical progress indicator を使う

## 近縁パターンとの区別

- vertical progress indicator は直列の工程で、前が終わらないと次に行けないことを左の縦線で表す。
  入れ子にしない（Material Design 2 の明文）。工程の中の作業群を見せたいときは、
  工程の本文にこのパターンを図として置く
- チェックリストは 2 状態（済 / 未）で階層を持たない
- tree view は構造の閲覧用で、状態を持たない

現在地は青（雛形の `--link`）で 1 つとは限らない。並行して進む項目があれば複数が「現在」になる。
色だけに頼らず、`.st` の語（完了 / 現在 / 未着手）と凡例を必ず付ける。
