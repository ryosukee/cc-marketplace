# bucket columns

複数の案を列に並べ、同じ分類のキーの下に何が入るかを対比する。
列は 2 に限らず、入る数だけ折り返す。

## 使ってよい条件

- 案ごとに「同じ分類軸の下に何が入るか」が違い、その差が判断の中心にあるとき
- 1 つの分類に複数の項目が入るとき。表にすると 1 セルが箇条書きになって破綻する
- 案が 2 つ以上。3 つ以上でも同じ書き方で通る

## 使ってはいけない条件

- 案ごとの違いが 1 セル 1 値で表せるとき。比較表のほうが横比較できる
- 分類軸が 4 つを超えるとき。列の中が縦に伸びて、案どうしの対応が取れなくなる

## 近縁パターンとの区別

比較表と目的が近い。分かれ目は 1 セルに入る項目数で、1 つなら表、複数なら bucket columns。
表の「列 = 選択肢、行 = 観点」の形が保てるうちは表を使う。
