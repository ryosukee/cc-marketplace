# 条件付き説明と順位・数値回答

確認フォームで、回答に合う説明を開く場合、全項目の優先順位を答える場合、範囲内の数値を答える場合に使う。
ページ固有の script や図の markup に操作を作らず、生成元 JSON と共通実装を使う。
使うページにだけ、組み立てが必要な CSS と JavaScript を含める。

## 回答に応じた説明

条件付きの説明を `conditional` ブロックへ入れる。設問の判断材料の一部にも使える。
該当する説明は開き、他の条件は見出しを残して折り畳む。他の条件も見出しから手動で開ける。
回答が変わって該当状態が切り替わるまで、手動の開閉を保つ。

```json
{
  "conditional": {
    "title": "試作から始める場合",
    "when": { "question": "q1", "equals": "試作から" },
    "blocks": ["短い試作で操作を確かめ、結果を次の調査へ使う。"]
  }
}
```

- `title` は空でない見出し。リンクや脚注参照は置かず、出典は `blocks` 内に置く。
- `when.question` は、並び順から付く設問 ID（`q1` など）。節を並べ替えたら参照先も確かめる。
- `when.equals` は選択肢の値。通常は `label` から記法を外した文字列。
  複数選択ではその値が選ばれていれば該当する。「その他」の自由記述は参照しない。
- 項目別選択を参照する場合は `item` に項目 ID も書く。
  例: `{ "question": "q2", "item": "owner", "equals": "自分" }`。
- 数値回答を参照する場合は `equals` に範囲と刻みに合う数値を書く。例: `{ "question": "q3", "equals": 0 }`。
  初期値を表示しただけの未回答や無効な入力は該当しない。順位回答は条件の参照先に使わない。
- 説明節全体を条件付きにする場合は、`kind: "explain"` の節に同じ `when` を書ける。
  その節の番号と見出しは、条件外でも残る。1設問にだけ効く判断材料は、その設問の `blocks` に置く。

条件は説明を開閉するためだけに使う。設問本体を条件分岐させず、設問数・番号・コピーする回答行を変えない。
未知の設問、値や項目、宣言外の式は source 検査で止める。
参照する値が未回答では条件付き説明を折り畳むが、全文は HTML に残す。印刷と JavaScript 無効時には全条件の説明を開く。

## 全項目の順位

```json
"question": {
  "type": "rank",
  "label": "優先順位",
  "text": "作業で優先するものを並べる。",
  "options": [
    { "label": "読みやすさ" },
    { "label": "操作のしやすさ" },
    { "label": "実装の速さ" }
  ]
}
```

`options` は二つ以上で、値を重複させない。全項目を上から順位順に並べる。
ドラッグハンドルはマウスとタッチで移動でき、上下ボタンはキーボードでも操作できる。
移動後の順位を読み上げ用の状態欄に知らせ、上下ボタンで移動した後も同じ項目へフォーカスを残す。
Escape またはポインター操作の取消しでは、ドラッグ中の変更を確定しない。

初期順序を表示しただけでは未回答。並べ替えるか「この順序で回答」を押すと回答済みになる。
`multiple`・`items`・推奨バッジ・「その他」は付けず、設問全体への補足欄を付ける。
コピーは `順位: {"order":["読みやすさ","操作のしやすさ","実装の速さ"]}`。
受領時は `value: null` と `order` に保存し、未回答の `order` は `null`。
欠落・重複・未知の項目を含む回答や下書きは受け入れない。

## 範囲内の数値

```json
"question": {
  "type": "number",
  "label": "試作の時間",
  "text": "試作に使う時間を答える。",
  "number": { "min": 0, "max": 8, "step": 0.5, "initial": 2, "unit": "時間" }
}
```

`min`・`max`・`step`・`initial` は有限の数値。`min < max` とし、`step` は正数にする。
`min` を起点とした刻みで `max` と `initial` に到達できる値を使う。`unit` は任意の単位表記で、リンクや脚注参照は置かない。
`options`・`multiple`・`items`・「その他」は付けず、設問全体への補足欄を付ける。

ブラウザ標準の range と number を同期する。初期値の表示だけでは未回答。
値を変更するか「この値で回答」を押すと回答済みになり、0 も回答として扱う。
空欄、範囲外、刻み違い、非有限の値は回答として確定せず、コピー操作も止めて入力欄へ戻す。
入力途中の無効な値は下書きに残し、再読込後も未回答として訂正できる。範囲へ丸めて回答に置き換えない。

コピーは `数値: {"value":2.5}`。受領時は `value: null` と `number: 2.5` に保存する。
未回答の `number` は `null`。数値を文字列にした payload、未知のキーや範囲・刻みの不一致は受領を止める。

## 保存と受領後

順位・数値も、回答進捗、設問カードのマーカー、下書きの復元、コピー、補足、リセットへ連動する。
下書きは表示中の値と回答済みかどうかを別々に保存し、初期値を復元しただけで回答済みにしない。
リセットは初期順序・初期値へ戻して未回答にする。受領済みのページは入力とリセットを止め、受領した回答を再表示する。
貼り付けた回答は既存の `record-answer.mjs` で受領し、原文を加工しない。

狭幅と広幅の切り替えでは入力ノードを移すため、並びと数値は維持される。
動きを減らす設定でも同じ操作を使える。JavaScript 無効時は全項目・数値範囲・説明を残し、回答は会話へ記入するよう案内する。
