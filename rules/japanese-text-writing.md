# 日本語テキストの執筆規範

日本語で出力するすべての場面（ファイル・ターミナル返答・HTML）に適用する。
詳細規範は ./japanese-text-writing/references/ 配下にあり、この rule は入口だけを担う。

## タイプ判定

出力の種類で読むものを決める。判定は書き出す直前に行う。
ツールの結果を受け取って、そのまま最終メッセージを書き始めない。
調査・比較・検証の依頼で、着手の時点で分量が読めるならそこで決めてよい。

- 数行の応答・進捗報告 → 何も読まずに下の最小規範で書く
- まとまった文章（複数段落の文書・調査まとめ・長い返答）→ 詳細規範の core を読み、
  種別判定表に従って該当種別の規範を重ねる。スクロールが必要な重厚な報告・
  比較表を伴う報告は HTML ページ（html-communication skill）で提示する
- 確認・質問 → 少数はフリーテキストで聞く。設問が多い・前提説明が長い確認は
  HTML フォームにする。判断が 2 件以上なら 1 件ずつ順に出すか HTML にまとめ、
  1 メッセージに並べない（最初の判断に答えるのに最後まで読む必要があるなら分割する）。
  選択肢に出てくる語は、選択肢より前に実体を書く。
  他の文書の文面をそのまま貼らない。前提を共有した読み手向けに書かれているため通じない

## 数行返答の最小規範

最重要の一文（何が起きたか・何が分かったか・何をしたか）から始め、
次のアクションを示して終える。前置き・装飾・同じ内容の言い換えを付けない。
失敗・未完了を成功と紛れる書き方にしない。
