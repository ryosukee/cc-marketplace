# 論文の規範

学術的に主張・証明する文書に適用する。例: 論文、研究報告、学術寄りの厳密な記事。
読者は主張とその論証を検証する。

## 定型構成

- 文書レベルではアブストラクトで結論を前置きする。本文の節順は分野の型に従い
  （実証系は IMRaD: 序論・方法・結果・考察）、型がある分野で独自の構成を発明しない
- アブストラクトは本文の縮約（目的・方法・結果・結論を各 1〜2 文）
- 序論で「何が未解決で、本稿が何を加えるか」（先行研究との差分）を明示する

## 論点の回収

- 前方に送った論点（例: 「次節で扱う」）は必ず回収する

## 引用

- 出典は主張単位で対応が取れるように付ける。孫引きしない。原典に当たれないときは孫引きと明示する

## 文体

である調で統一する。
