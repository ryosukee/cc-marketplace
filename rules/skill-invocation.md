# 該当する skill は発動してから実行する

依頼が skill の発動条件に一致するなら、手順を覚えているつもりでも Skill ツールで発動し、
本文の手順どおりに実行する。記憶・要約で代替しない。

- コンテキスト残量の節約は省略の理由にならない。skill 本文のロードはその作業の一部
- 省略してよいのは、ユーザーが工程の省略を明示したときだけ
- 全工程を実行できない事情があるなら、省略する工程を先に申告して承認を得る

## why

実例（2026-08-10）: 「コンテキストが残り少ないからセッション終了して」の依頼で
session:end を発動せず記憶で簡略実行し、debrief と retrospective が丸ごと欠落して
差し戻された。skill 本文は正典で、記憶はその要約でしかない。
