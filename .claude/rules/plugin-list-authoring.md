# README.md の plugin 一覧の書き方

repo 直下の README.md の「プラグイン」にある、plugin 一覧の概要の書き方を定める。

## 概要には、plugin の目的と方針だけを書く

概要の 1 文目に、その plugin が何のためにあるかを書く。2 文目に、その目的をどう実現するかの方針を書く。
skill・hook・agent の名前、ファイルの配置、requirements、開発中の状態は書かない。

why: 中身は plugin の README が持つので、一覧にも書くと plugin を変えるたびに片方だけが古くなる。
