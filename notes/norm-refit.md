- 悪文検知の調査（2026-08-15、subagent 実測。実装判断は未承認）:
    - **LLM レビューの限界**: LLM judge の可読性評価は人間と相関しない（意味保存 r=0.77 に対し
      読みやすさ r=0.28、DETECT）。大きいモデルほど人間の読み時間から乖離する（TACL 2023、
      英語で厳密に単調）。人間の読解困難のうち「語を文脈へ統合するコスト」は言語モデルが
      構造的に予測できない（PNAS 2026、eye-tracking 368 名）。
      「並列に読めるから」という機序は直接検証され不完全（同時解析数を減らしても困難は再現せず）。
      対処の方向は、判定を尋ねず抽出を課す / 対象文だけ独立に見せる / 独立サンプルの解釈の
      分岐を見る / A/B 比較（参照付き評価で見逃しが 57%→26%）
    - **surprisal による測定**: 日本語では文脈を 3-gram 程度に制限したモデルが人間の読み時間を
      最もよく説明する（Kuribayashi et al. EMNLP 2022「過剰な作業記憶」）。日本語では
      perplexity 400 未満で相関が正に反転（ACL 2021）。判定用と測定用でモデルを分ける根拠。
      ただし絶対判定には使えない（日本語の同種実験で 3 値分類 0.36〜0.50、天井 0.55）。
      用途は推敲前後の相対比較とトリアージ。Anthropic API に logprobs は無くローカル小型モデルが要る
    - **名詞構文の機械検知**: 既存ツール（textlint 日本語 4 preset・proselint・write-good）は
      実測で検出ゼロ。自前ルール 2 系統（「の」連鎖 + サ変 2 つ以上 / 弱述語 + 裸サ変 4 つ以上）で
      正例 93%・実文書の誤検知 1.3%（2,829 文で実測）。textlint カスタムルール 60 行で動作確認済み。
      閾値を下げた変種は正常文でも 35〜41% 発火するため不可
    - **造語検知**: 辞書ベースの未知語検出は原理的に不可（既知語の再結合のため全形態素が既知）。
      上流文書との差分（名詞 + 「の」の句を抽出）で対象 4 語をノイズ 0 で抽出。
