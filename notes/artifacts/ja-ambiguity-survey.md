# 日本語の構造的曖昧性: 型カタログと検出の実装可否

調査日 2026-08-15。subagent 5 本 + 再委任で延べ 20 本超。
頻度はこの repo の日本語 md 4,941 文を GiNZA で解析した実測（発火頻度であって精度ではない）。

起点は「repo にコミットした宣言だけで」が 2 通りに読めるというユーザー指摘（2026-08-15）。
現行の DG14「修飾語は係り先の直前に置き、スコープが曖昧なら「」で括る」では検出できないことが分かり、
型を網羅的に洗い出した。

着手時期は将来。台帳 [norm-refit 台帳](../norm-refit.md) の未解決課題と作業メモから参照する。

## 結論

起点の型（内の関係 / 外の関係）は優先度で 3 番手以下。この repo で最も多いのは
テ形・連用中止の接続関係（無標 22.7% / テ形 17.0%）と主題「は」のスコープ（5.0%）。
既存の lint ツールにこれらを検知するルールは 1 件も無い。
「多義かどうか」の総合判定は精度 0.5 前後が上限で、狙うべきは多義そのものではなく
多義になりやすい表層構造。

## 前提: 内の関係 / 外の関係の成立条件

2 条件の連言。寺村の判定基準そのもので、独立した 3 本の subagent が同じ結論に到達した。

1. 底の名詞が内容節をとれる（外の関係が可能）
2. 修飾節述語に空き格があり、その名詞がそこに入れる（内の関係が可能）

「彼が来た事実」は条件 1 だけを満たし条件 2 を満たさないため曖昧にならない。
「repo にコミットした宣言」は「宣言をコミットする」でヲ格に入るため両方を満たす。

サ変名詞は手がかりとして弱い。2 条件を満たす候補 96 件のうちサ変 44 件（46%）、非サ変 52 件（54%）。
条件 2 は名詞の性質ではなく「修飾節述語と名詞のペア」で決まる。
非サ変でも項になれる名詞の実測出現数は 内容 42 / 結果 36 / 情報 35 / 判断 25 / 理由 15 /
説明 12 / 方針 12 / 計画 11。ただし述語を VERB に限定するだけで候補の大半が落ちる
（未カバー側は 属する・必要・長い・多い が支配的）。

## 型カタログ

### 係り先

**A1 前置修飾語の係り先**<br>
修飾語は必ず被修飾名詞の左に置かれ、作用域の右端を標示するものがない。
例「彼は美しい彼女の歌声を聞いた」（美しいのは彼女 / 歌声）、「小さな書斎の窓」。
検出は `(形容詞-自立|連体詞|動詞連体形) + 名詞+ + 助詞-連体化 + 名詞`。
解消は語順が第一手段で、本多勝一の 2 原則（節を先・句を後 / 長い修飾語を先）を
実測 6 対すべてで再現した。読点は NP 単独なら遠い主要部へ振り替わるが（3/3）、
後続に述語があると連体読み自体が壊れて advcl に滑る（3/3）。文中では読点を使わない。<br>
出典: 山中信彦 (1988)『言語研究』94 / 金子康朗 (1987)『基礎心理学研究』6(1) /
潮田明 (2012) NLP2012 C4-7 / 公用文作成の考え方 Ⅲ-3 ク / Sun 日本語スタイルガイド 2007 p.29

**A2 連体修飾節の内の関係 / 外の関係**<br>
上記 2 条件の連言。寺村の判定基準は「底の名詞に格助詞を付けて修飾部のどこかに収まるか」。
文献例は「肖像権を認めた判決」（丸元・乾 2000）、「魚を買ったおつり」（高瀬・松本 2017）。
最良の検出構成は「acl の head が内容名詞リストに属する」×「述語が VERB」×「述語が他動詞」×
「節内に obj が無い」で 1.84%（91/4,941）、手検分の精度およそ 5 割。
kuromoji のみでも直前の用言 + 節左端までのヲ格走査で 1.87% まで近似できた。<br>
内容名詞リストの実物は KNP 同梱 `dict/ebcf/case_soto_words.txt` 109 語が BSD 3-Clause で
唯一無料入手可能。ただし宣言・報告・主張・指摘は入っていない。
金城ら (2002) が毎日新聞 5 年分 724 万文から 100 語を「という必須 40 語 / 任意 60 語」に
分けた表も使える。<br>
解消は述語に開いて格助詞を明示する（「宣言を repo にコミットした」）が最も確実。
被修飾名詞に修飾を 1 つ足す（阿辺川 2005 の素性 4）も内の関係に確定する。
**「という」の挿入は使えない**。寺村自身が分類基準として明確に退けており、
限定的修飾では不自然になり（「？外国人に日本語を教えるという仕事」益岡 1994）、
内の関係にも「という」は入って伝聞・評価の読みを生む。実測でも係り受け木が変わらない。<br>
判別精度の上限は阿辺川・奥村 (2005)『自然言語処理』12(1) の 7 素性 + 決定木で正解率 0.902
（baseline「全部内」0.774、格フレームのみ 0.830）、外の関係の再現率 0.762 が公表最良。
この repo での「という」前接率は 0.3%（7/2,516）。<br>
出典: 寺村秀夫 (1975-78)（NINJAL が英訳全文を公開）/ 阿辺川・奥村 (2005) /
高瀬・松本 (2017) NLP2017 P2-2 / 金城ほか (2002) NLP2002 P1-9 / 京大コーパス格関係アノテーション基準。
**日本語のスタイルガイド（JTF・JIS・公用文・記者ハンドブック・Microsoft ja・Sun）に
この型の条項は 1 件もない。**

**A3 副詞・連用修飾語の係り先**<br>
例「彼女は彼に静かにボートをこぐように言った」、「ワープロで翻訳した結果を修正する」。
検出は `advmod` の距離 3 以上かつ間に別の VERB。実測 0.5%（16 件）。
読点がこの型に最も効く（6 対中 5 対で係り先が変化）。<br>
出典: 平井・梶・芦沢 (1990)『情報処理学会論文誌』31(10)。
矢澤真人 (1987/88/89) が唯一の正面からの記述文法研究だが本文未取得。

**A4 主節 / 関係節（日本語の garden path）**<br>
節境界を明示する統語的指標がなく、後置された主要部が現れるまで確定しない。
例「山田が高橋を殴った佐藤を叱った」。
英語の garden path は先頭側で誤ってコミットして崩れるが、日本語は確定の遅延で向きが逆。<br>
出典: 井上雅勝 (2006)『Cognitive Studies』13(3) / Mansbridge &amp; Tamaoka (2019)
*Journal of Japanese Linguistics* 35(1)

**A5 従属節の階層（南不二男の A/B/C 類）**<br>
同一の接続形式が複数の類の節を作りうる。類が決まらないと主語共有の義務性・
否定やモダリティの作用域・焦点になれるかがすべて決まらない。
南自身が「A 類、B 類、C 類といった区別は接続助詞のいかんによってあらかじめ
決められるものではない」と述べており、「ながら = A 類」型の固定リストは不正確。
白井ほか (1995)『情報処理学会論文誌』36(10) が階層順序で係り先を決定し、
曖昧な述語 356 件 → 54 件、第 1 候補正解率 92% → 98%。<br>
出典: 吉本啓 (1993)『言語研究』103 / 大堀壽夫 (2012) NINJAL シンポ資料

### スコープ

**B1/B2 否定のスコープ・全称量化 × 否定**<br>
例「力を出し切って敗れたわけではない」、「全部食べなかった」。
松吉ほか (2013, NINJAL) のアノテーションで、新聞 304 個の否定要素のうち
103 個（33.9%）が 2 名の作業者で不一致。基準に「解釈に複数の可能性が考えられる場合は
焦点はスコープ全体とする」という条項が置かれており、多義の存在が運用ルールとして公認されている。
焦点がスコープ全体でない割合はレビュー 29% / 新聞 24%。
検出は `(すべて|全て|全部|常に|必ず|いずれ) … (ない|ず|なかっ)` で実測 0.3%（17 件）。
解消は語彙置換のみ（「どれも〜ない」/「一部は〜ない」）で、読みの判定は機械に渡せない。<br>
出典: 『現代日本語文法3』第7部 第3章（本文未確認）/ 松吉ほか (2013) JCLWorkshop No.3 /
松吉 (2014)『自然言語処理』21(2) / 公用文 Ⅲ-3 コ

**B3 とりたて詞 × 否定**（出典が最も厚い領域）<br>
例「寿司だけを食べない」が 2 通り。語彙で決まり、「まで」は二義、「さえ」は一義、
「までは」は狭スコープのみ。階層は `だけ｜まで｜は｜さえ・も`。
格助詞との承接順（`太郎にだけ` / `太郎だけに`）でも二義になる。
検出は `(だけ|のみ|まで|も|しか|ばかり|こそ)/助詞 … (ない|ず|なかっ)` で実測 3.6%（177 件）。
解消は一義の語への置換（まで → さえ / までは）。
松吉ほかの実測では否定の焦点 373 件のうち 35%（129 件）にとりたて詞が付いていた
（は 79 / しか 41 / も 8 / だけ 1）。<br>
出典: 茂木俊伸 (1999)『日本語と日本文学』28 / 茂木 (2000) 国語学会秋季大会要旨集

**B4 数量詞のスコープ**（英語と結果が逆）<br>
日本語は rigid scope language で、複数量化子他動詞文の目的語 QP は主語 QP より
広いスコープを取れない。「3人の学生が2冊の本を読んだ」型は原則として曖昧にならない。
英語 *Someone criticized everyone* は両読み可能だが、日本語「誰かが誰もを責めた」は
`∃ >> ∀` のみ。ただしかき混ぜは曖昧性を生み、その効果は節内かき混ぜに限られる。<br>
出典: Goro (2007) University of Maryland 博士論文（Hoji 1985: 336 を引用）

**B5 数量詞遊離**<br>
例「私は昨日会った数人の学生を招待した」（全体読み）/「私は昨日会った学生を数人招待した」（部分読み）。
量的制約として `5個のリンゴを3個食べた` は可、`*3個のリンゴを5個食べた` は不可。
検出は `nummod` の head が obl/advmod で実測 3.3%（164 件）。
形態素解析が壊れる例あり（「学生が3人本を2冊読んだ」で `人本` が 1 語になる）。<br>
出典: 尾谷昌則（法政大学）/ 小林ほか (2005) NLP2005 P2-2

**B6 選言・連言 × 否定**（英語と逆向き）<br>
日本語の「か」「も…も」は Positive Polarity Item で局所否定のスコープ下に解釈できない。
英語 *John doesn't speak French or Spanish* は両方話さない（ドモルガン読み）だが、
日本語「ジョンは仏語か西語を話さない」は「仏語を話さない**または**西語を話さない」。
英語 *doesn't speak both A and B* はどちらかを話さないだが、
日本語「AもBも話さない」は両方話さない。<br>
出典: Goro (2007)

**B7 主題「は」のスコープ**（英語に対応物なし）<br>
主題は南の C 類節（最上位）の構成要素なので下位の従属節をすべて跨ぐ。
三上の「勢力を文末まで及ぼす」（1970: 12）。
1 文に「は」が 2 つ以上あると先頭の「は」が主題とも対比とも読める。
久野 (1973) の「最初のハ句だけが主題解釈」に対し、上野 (2017) は
「最初のハ句が必ず主題解釈になるというものではなく、対比が連続することも許容する」と明言。
従属節内の「は」は必然的に対比。
主語一致が類で変わる（A 類は主題の有無によらず義務、B 類は非主題なら不要・主題なら義務、C 類は不要）。
書き言葉に固有で、話し言葉では音調（post-focal reduction、prominence-lending rise）が
主題 / 対比を解消するが、書き言葉ではこの手がかりが全部落ちる。
検出は 1 文の「は」個数、または「は」の後に従属節マーカーで実測 5.0%（247 件）。
解消は主題を従属節の後ろへ移すか文を分ける。<br>
出典: 三上章 (1960)『象は鼻が長い』/ 吉本啓 (1993)『言語研究』103 /
上野貴史 (2017)『広島大学大学院文学研究科論集』77 / Oshima (2009) PACLIC 23。
「ピリオド越え」は学術文献での使用を確認できず、三上の原文を使うのが安全。

**B8 原構造の違い（感情述語）**<br>
例「猫は家内が好きでね」（宮本輝『避暑地の猫』の実例）。<br>
出典: 野田尚史 (2002)「日本語のあいまい文」『日本ファジィ学会誌』14(1), 7-14（J-STAGE 全文公開）。
日本語の構造的多義を体系的に分類した唯一に近い一次文献。

### 並列・境界

**C1 並列句のスコープ**<br>
並列標識（と・や・および・または・読点）は左の項の直後に付く後置標識で、右の項の終端を標示しない。
主要部後置なので並列句の右端は主要部まで未定。
構造テンプレートは `［名詞1］と［名詞2］の［名詞3］`（野田 2002）。
実例「新しいリカちゃんと初代リカちゃんの復刻版」（朝日新聞 1992.2.20）、
「赤いシャツとジャケットを着た姉」（浅原・松本 2018）、「俺は校庭で岡田と林をなぐった」（金子 1987）。
検出は `(と|や)/助詞` の後方 6 形態素以内に `助詞-連体化 + 名詞` で実測 2.3%（114 件）。<br>
解消の実測: 括り出し（主題化）が最も確実（2/2 で並列から外れる）。反復も確実だが冗長。
読点は 8 例中 5 例でしか係り先が変わらず不安定。
JIS の両端マーキング（「〜と〜とを」）と「」括りは係り受け木を変えない（「」は逆効果で解析が崩れる）。<br>
語彙選択による階層明示が唯一の制度的解法。JIS Z 8301:2019 附属書 H.3.2.2-H.3.2.5 と公用文 Ⅱ-1。
「や」は「及び / 又は」のどちらか曖昧なので用いない（JIS が明示的に禁止）。
「又は」は常に最上位、「及び」は常に最下位。
最小対「刑法又は刑事訴訟法若しくは民事訴訟法」= 刑法 ∨ (刑訴 ∨ 民訴) と
「刑法若しくは刑事訴訟法又は民事訴訟法」= (刑法 ∨ 刑訴) ∨ 民訴。<br>
解析誤りへの寄与が最大。川原・黒橋 (2008) のウェブ 759 文で、並列キー文節は
全係り受けの 25.2% を占めながら全誤りの 40.8% を占める（3 モデルで 40〜42%）。
黒橋・長尾 (1994) では文長 30-50 字で並列出現率 42%、50-80 字で 80%、80 字以上で 92%。
文単位の完全正解率は並列なし 77% / あり 60% / 80 字以上 46%。<br>
UD が扱いを放棄している。Kanayama ら (2018) の実測で左主辞並列を採ると UAS 77.0 → 73.6。
理由は「並列 (conj) は他の係り受け (nmod や advcl) と決定的に区別できない」。
現行 UD Japanese は名詞句並列を nmod、動詞句並列を advcl として扱う。<br>
出典: Kurohashi &amp; Nagao (1994) *Computational Linguistics* 20(4) / 川原・黒橋 (2008) COLING /
浅原ほか (2019)『自然言語処理』26(1) / 平野敏彦 (2015)『広島法科大学院論集』11

**C2 部分並列**<br>
例「本を兄の太郎に｜ノートを弟の三郎に｜かしている」。並列項が統語木の部分木にならない。<br>
出典: 浅原・松本 (2018)『自然言語処理』25(4) / 丸山ほか (2016) NLP2016 P20-3

**C3 複合名詞の内部構造**<br>
名詞と接辞のみの連続で助詞が存在しないため手がかりがゼロ。
可能な構造数は 3 形態素 2 通り、4 形態素 5 通り、5 形態素 14 通り（カタラン数）。
例「野性生物保護」（left-branching）/「北海道農業会議」（flat）/「情報処理技術者試験」。
**唯一の既存 textlint ルールがここにある**（`max-kanji-continuous-len`、既定 6）。
RedPen は `LongKanjiChain`。解消は「の」「を」で分割するか動詞へ開く。<br>
出典: 佐藤・宮崎 (2006) NLP2006 D3-8 / 小林ほか (1996)『自然言語処理』3(1) / JIS Z 8301 H.2.5

**C4 接辞のスコープ**<br>
例「非常勤講師組合」（[非常勤講師]組合 / 非[常勤講師組合]）、「再開発計画」。
既存解析器は「接頭辞は受け側になることは極めて少ないので先につなぐ」と最狭スコープを仮定しており、
「非[常勤講師組合]」型は原理的に取り違えられる。
特許ライティングマニュアル 7-6 が「「〜的」「〜性」「〜化」「〜上」「〜式」「〜型」などの
接尾辞をつけた表現は、定訳がない場合があり、あいまいな意味にもなりやすいので注意する」。
**日本語の接辞スコープ多義を正面から扱った査読論文は CiNii の複数クエリで 0 件。**

**C5 読点の有無で係り先が変わる**<br>
実測でこの型の規模が出た。読点を含む 700 文から読点を除去すると 57%（404 文）で
係り受けが変わった。効き方は修飾のタイプで違う。

| 対象 | 読点で係り先が変わった | 備考 |
| --- | --- | --- |
| 連用修飾（副詞） | 5/6 | 最も安定 |
| 並列 | 5/8 | 不安定 |
| 連体修飾（NP 単独） | 3/3 | 遠い主要部へ振り替わる |
| 連体修飾（後続に述語あり） | 3/3 が破壊 | advcl に滑る。使ってはいけない |

読点は意味的自然さに負ける。新国佳祐 (2015) 東北大学博士論文の実測で、
読点なし条件では意味的に自然な解釈が 97〜99%。意味と対立する位置に読点を打っても
自然解釈の割合は 19.6〜23.8 ポイント下がるだけ。同論文の結論は
「読点は確かにある程度は文の構造決定に寄与するが、少なくとも意味的な自然さを覆して
不自然な解釈を選択させるはたらきには限界がある」「読点の使用において最も注意すべきと
考えられるのは、書き手の側と読み手の側の知識や背景、常識が特に大きく異なる場合である」。<br>
これは今回の起点（「宣言」が settings.json を指す非標準用法）と正確に整合する。
読み手が意味的常識で係り先を補える前提が崩れる領域でだけ、構造的な手当てが要る。<br>
読点の位置は機械判定できない。村田ほか (2010) が京都コーパス 34,282 文で、
係り受け関係にある隣接文節間への読点挿入率 3.04% に対し、係り受け関係にない隣接文節間は 36.99%、
CaboCha の係り受けを素性に使って F 値 75.18。
宮地ほか (2019) は読みにくい語順の文では F 値が 62.61 → 48.88 に落ちる（直したい文ほど当たらない）。<br>
通説への反証として荻野・成原 (1989)「読点を伴う連体修飾が直後の体言列に係りにくいという
通説に対し、実際に直後の文節に係るものの数は、例外と考え得る範囲を越えている」。<br>
JTF 4.0 の 3.1.2 は係り先が変わる例文の対を並べているが、どちらに打つべきかの基準は書かれていない。

### 助詞・形態の多機能性

**D1 属格「の」と「の」連鎖**<br>
「の」は N1 と N2 を結ぶ形式的機能しか担わず意味関係を一切標示しない。
渡辺実 (1971) はこれを連体修飾の「超論理的性格」と呼ぶ。
奥津敬一郎 (1978) が 21 分類。うち 18（後続サ変動詞の主語）と 19（同目的語）の並存が
主格 / 目的格の多義を生む。例「花子の絵」。
西山佑司 (1991)『慶應義塾大学言語文化研究所紀要』23 が「NP1のNP2」を 5 通りに定式化。
検出は `助詞-連体化` の連続。「の」を 3 個以上含む文は 4.3% だが、
厳密な連鎖（N の N の N の N）はこの repo で 6 件のみ、nmod 3 段は 12.0%。<br>
既存ツールに落とし穴がある。`no-doubled-joshi` v5.1.1 のソースで、非 strict モード
（preset の既定）が連体化「の」・格助詞「を」・接続助詞「て」を明示的に例外化している
（`matchExceptionRule` 行 35-65）。README も「曖昧性があるため助詞が連続していても
デフォルトではエラーとして扱いません」と述べる。構造的多義に最も関わる 3 つが素通りする。
strict 化するとこの repo で 101 → 869 件（8.6 倍）、内訳は の 514 / に 99 / を 90 / は 56 / が 44。<br>
規範側の理由付けが多義ではない。公用文 Ⅲ-3 キ「同じ助詞を連続して使わない」の理由は
「稚拙な印象を与えてしまうおそれがある」。Microsoft ja 4.2 も "for clarity" のみ。
「の」連鎖が生む入れ子構造の多義そのものを理由に挙げた規範は 1 件もない。<br>
RedPen には専用 Validator がある（`JapaneseAmbiguousNounConjunction`）。
kuromoji トークン列に対する 4 状態のステートマシンで、品詞第 1 階層と表層「の」だけを見る。

**D2 「が」の多義**<br>
主格 / 対象格 / 総記 / 中立叙述 / 接続助詞の 5 用法。
総記と中立叙述の対立は英語にない（英語は強勢・分裂文で表し分ける）。
例「花子が好きな男性は多いです」。<br>
出典: 久野暲 (1973)『日本文法研究』/ 鈴木彩香 (2014) 筑波大学『言語学論叢』オンライン版7

**D3 「られる」の 4 用法**<br>
受身・可能・自発・尊敬。例「田中さんは山下さんに英語を教えられた」で
尊敬なら田中さんが教えた、受身なら山下さんが教えた（格配置が反転）。
成立条件は「受け身文の動作主を表す『に』と能動文の対象を表す『に』が同じであること」で、
られるの多義とニ格の多義が重なって初めて反転が起きる。
共起制約で解消される例あり（「他人に対して」は可能とは共起するが受身とは共起しない）。<br>
出典: 高橋芽衣子 (2010)『名古屋大学国語国文学』103

**D4 「に」「で」「から」「と」の多機能性**<br>
例「出発が六時に決まる」、「私は太郎とレジの仕事を交替した」。
書き換えの一次資料は特許ライティングマニュアル 7-1 の対応表
（「アルミの第1層」→「アルミからなる第1層」、「押圧具で押圧する」→「押圧具によって押圧する」）。
長尾真 (2008) の 8 項目の第 5 項が同じ規範。
「より」は JIS H.3.2.8 と公用文 Ⅱ-5 イ(ア) が禁止条項を持つ。

**D5 「〜ている」「〜てある」のアスペクト多義**<br>
例「木の葉が落ちている」（落下中 / 落ちた状態）。<br>
出典: Hasegawa (1992) BLS 18

**D6 再帰代名詞「自分」のスコープ**<br>
例「太郎は花子に自分の部屋で勉強させた」。英語では his/her で解消される。

### 省略

**E1 格助詞の省略（ゼロ助詞・無助詞）**<br>
用語自体が学説対立を反映する（省略説 / ゼロ助詞説 / 無助詞説）。
三枝 (2005) の切り分けは「格を補っても表現内容が変わらないなら省略、
補いにくい・補うと意味が変わるなら無助詞格」。
「は」「が」「を」「へ」は落ちやすく、「に」「で」「から」「と」は落ちにくい。
解析器への影響の実測（柴田ほか 2019、京大コーパス / ウェブ）:
ヲ格 97.7/98.7、ニ格 94.8/96.3、ガ格 91.6/94.4、未格 88.1/90.0、
無格 83.2/91.1（新聞）・75.5/89.4（ウェブ）。
BERT で最も改善したのが無格（+7.9 / +13.9）で、文脈から補える情報であることも示す。
実測で GiNZA も壊れた（「設定ファイル読み込んで反映する」で `読み込ん<-ファイル(dep)`）。
英語に対応物なし（英語は格を語順で標示するため落とす操作自体がない）。<br>
出典: 三枝令子 (2005) 一橋大学留学生センター紀要8 / 小屋逸樹・辻幸夫 (2008)

**E2 ゼロ代名詞・受身の動作主消失**<br>
文章内ゼロ照応と外界ゼロ照応（照応先が文章中に出現しない）に分かれる。
連体修飾節との相互作用で「注射した人は誰ですか」が 2 通りになる。
Shimazu ら (2020, LREC) の先行詞距離別で、文単位 NMT は d=0 なら 88.2%、d=1 で 57.5%、d=2 で 56.0%。
人間も文脈なしなら d=1 で 27.3%、d=2 で 26.0%（偶然 50% を下回る）。文脈ありなら 93.5/92.2。<br>
規範への含意: 「主語を毎回書け」ではなく「先行詞が同じ文の中にないなら書け」のほうが
実測の構造に合い、冗長も少ない。
検出は `(さ|ら)+れ` で `に|によって|により` が同一文にない、で実測 3.6%（176 件）。
解消は能動化（nsubj が明示され木も変わる）。<br>
出典: 萩行ほか (2014)『自然言語処理』21(3) / Shimazu ほか (2020) LREC / Nagata &amp; Morishita (2020) LREC

**E3 述語の省略・体言止め**<br>
**体言止め・見出し文の構造的多義を正面から扱った文献は見つからなかった**（CiNii 0 件）。
規範側は Microsoft ja 4.2 が良悪例を持つ（「オブジェクトの種類を選択」正 /
「オブジェクトの種類の選択」誤）。英語側は同型の説明あり。

### 節接続

**F1 テ形・連用中止形の接続関係**（この repo で最頻）<br>
テ自体は「近い過去と接続」しか表さず、付帯状況 / 継起 / 原因理由 / 並列のどれになるかは
述語の意志性・アスペクト・心理性と文脈で決まる。
例「子供達は落ち葉を集めて遊んだ」、「その作家は関西に疎開して芦屋を舞台とした長編小説を書いた」
（吉永 2012 が「両義的である」と明記）。
最も危険な型は「田中刑事は血まみれになって逃げ出した泥棒を追いかけた」（北原 1981）で、
テ形節が連用節なのか連体修飾節の内部なのかが決まらない。
否定作用域とも相互作用する（「犯人はガラスを割って侵入しなかった」）。
内丸 (2006) と吉永 (2012) は付帯 = VP 付加・並列 = TP/CP 等位で一致し継起・因果の扱いで割れる。
この割れ自体が構造位置の非決定性の証拠。
検出は `advcl` の head が `advcl` で 6.5%。より広く無標の連用中止（mark なし advcl）が
22.7%（1,123 件）、テ形節ありが 17.0%（839 件）、混在が 5.1%。<br>
解消は明示的接続表現への置換が有効で、`advcl` が `acl + obl`（形式名詞つき）に変わり
関係が機械可読になる（「変更して再起動」→「変更したため再起動」/「変更したうえで」/
「見たあと」/「使うことで」/「かつ」）。文の分割が最も確実。<br>
出典: 吉永尚 (2012)『園田学園女子大学論文集』46 / 内丸裕佳子 (2006)『日本語の研究』2(1) /
北原保雄 (1981)『日本語の世界6 日本語の文法』/ 公用文 Ⅲ-3 カ / Sun 2007 p.29

**F2 条件節・理由節のスコープ**<br>
「から」は B 類・C 類の両方に、「ので」は分析が割れる。
B 類なら理由節は命題の内側で主節の否定・焦点・モダリティの作用域に入り、C 類なら外側。
証拠は「人生には終わりがある｛*ので / から｝こそ」の焦点化可否。
理由節の中に「は」を入れるかどうかが文の焦点をどこに置くかの宣言になる（野田 2007）。
「から」節は少なくとも 3 通り（B 類 / C 類 / カラ2 = 発話の正当化）。
英語との差: 英語は because 節が後置されるため主節の否定が処理済み。
日本語は理由節が前置され否定が後から来るため、作用域内か外かが未確定のまま保持される。

**F3 引用節「と」のスコープ**（英語に対応物なし）<br>
「と」は引用の終端を標示するが始端を標示しない。書き言葉では引用符が任意。
例「太郎は花子に静かに本を読むように言った」。解消は「」で括る（この型では有効）。<br>
出典: 浜辺ほか (2009)『自然言語処理』16(1)（SVM で始端・終端を決定する手法の提案自体が
始端の非決定性の証拠）

**F4/F5 連用節と連体節の境界、補足節と連用節**<br>
「唐辛子を食べた時、涙が出た」、「協議を重ねた結果」、「名前を呼ばれたのに気がつかなかった」。
「〜した結果」「〜した時点」「〜した場合」は連用節にも連体節にも読める。
丸山らは「時」の位置に入りうる名詞（瞬間・途端・後・際・前・間・頃・うち・たび・折）の
網羅が困難だと述べる。<br>
出典: 丸山岳彦ほか (2016) NLP2016 P20-3

### ヴォイス（すべて英語に対応物なし）

**G1 受身（直接 / 間接 / 持ち主）**<br>
例「太郎が花子に子供をほめられた」。共指かどうかが表層に現れない。
間接受身ではニ格句が義務的（`*太郎が泣かれた` は非文）なので、
ニ格を省略した「〜られる」文は間接受身の読みを失う（省略が多義を減らす珍しい例）。<br>
出典: Ono, Naoyuki (2003) ACL Anthology Y03-1004

**G2 使役（強制 / 許容 × つかいだて / みちびき）**<br>
例「太郎は花子に髪を切らせる」が 4 通り。早津は後者の軸を「つかいだて」「みちびき」と命名し、
強制 / 許可とは直交する別軸だと提案。
**「ヲ使役 = 強制 / ニ使役 = 許可」は否定されている**（早津 2015 脚注21。
国立国語研究所 1964、早津 1999、許 2005 が「実相にあわない」と指摘）。
日本語教育の教材で広く流布しているが実証研究では支持されていない。<br>
出典: 早津恵美子 (2015)『言語研究』148

**G3 授受表現**<br>
テモラウは依頼的 / 許容的 / 単純受影的の 3 通り。
テモラウ（ガ = 受影者、ニ = 動作者）とテクレル（ガ = 動作者、ニ = 受影者）で格配置が逆転するため、
格が省略されると方向が決まらない。<br>
出典: 山田敏弘 (1999)『阪大日本語研究』11

### 表記（漢字仮名交じりに固有）

| 型 | 曖昧になる媒体 | 例 |
| --- | --- | --- |
| 同音異綴異義 | 話し言葉のみ | 「ジカンキュウ協議」= 時間給 / 次官級 |
| 同綴異音多義 | 書き言葉のみ | 「人気のない広島市民球場」= ヒトケ / ニンキ（朝日新聞 1991.10.17） |

書き言葉の規範に関わるのは後者。英語の homograph が近いが、
漢字 1 字あたりの読みが複数あるため規模が桁違い。

## 既存ツールのカバレッジ

**係り受けの曖昧さそのものを検知する textlint ルールは存在しない。**
textlint-ja の全 41 リポジトリ、npm の `textlint-rule` 全 250 件、
両 organization の issue 全文検索で、「係り受け」に言及するのは
`no-doubled-joshi` の issue 3 件のみで、内容は「できない」という結論。

> "同じ格助詞が一つの動詞に複数かかっていないか、またはかかっていても意味的に並立している場合を
> チェックできるとよいのですが、そうすると単語（文節）の依存関係（係り受け）解析＋格の意味解析が
> 必要になるので、kuromojiではできなさそうです。"
>
> 出典: [textlint-rule-no-doubled-joshi issue #4](https://github.com/textlint-ja/textlint-rule-no-doubled-joshi/issues/4)

`preset-ja-technical-writing` 12.0.2（全 23 ルール）を曖昧例文 15 にかけて検出 1 件のみ
（`max-kanji-continuous-len` が「適用範囲確認手順」を指摘）。
この repo 全体では 653 件の違反が出るが、内訳は ja-no-mixed-period 274 /
sentence-length 199 / no-doubled-joshi 101 で、構造的多義を狙ったルールからの検出は 0 件。

| ツール | 多義への対応 |
| --- | --- |
| textlint preset-ja-technical-writing | ゼロ。近似は文長 100 字・読点 3 個・同一助詞連続・漢字連続 6 字 |
| textlint preset-JTF-style | ゼロ。JTF の読点条項は対応表で `不可` と明記 |
| textlint `no-ambiguous-process-noun-chain` | 唯一の「曖昧性」ルール。npm 未公開。発火条件が 5 つの AND で極端に狭い |
| RedPen `JapaneseAmbiguousNounConjunction` | 「の」連鎖のみ。多義判定は一切なし |
| Just Right!7 Pro「修飾関係」「並列関係」 | 構造的多義を正面から扱う唯一の商用ツール。方式は非公開で修正案も出さない |
| Yahoo! 校正支援 API | ゼロ |
| Tomarigi | 係り受けを表示するが自動検出はしない |

JS 側の実装基盤は 2026-07 に変わった。[sasara](https://www.npmjs.com/package/sasara) 0.2.0 が
kuromojin トークンから文節係り受けを線形モデルで解き、Platt 較正済みの確信度を返す（UAS 83.31%）。
実測では ambiguous 12 文 vs 対照 12 文で最小確信度 0.713 vs 0.808、
文内ディップ 0.160 vs 0.085 と分離自体はする。
ただしこの repo の実文では min < 0.7 の文が 70.9%（記法を除いても 66.0%）で、
絶対閾値では運用できない。`sasara` を使った textlint ルールは現時点で 1 件も存在しない。

2 パーサの不一致を多義の信号にする案は、GiNZA（UD 単語係り受け）と sasara（文節係り受け）で
粒度が違い、素朴なアライメントでは対照群のほうが不一致が多く出て指標として機能しなかった
（実装が粗いことの結果で手法の否定ではない）。

### 精度の上限

吉田・河原 (2022, NLP2022 D3-1)「構造的曖昧性に基づく読みづらさの検出」は、
2 文のどちらが構造的に読みづらいかの 3 択で最高精度 0.500、
金の構文解析を与えた理想条件でも 0.549。
1990 年の平井ほかが既に「必要以上に多量の曖昧性を検出すると、
かえって前編集の作業効率に悪影響を及ぼす」と課題設定しており、36 年間そのまま。

現実的な着地は「多義そのもの」ではなく「多義になりやすい表層構造」の狙い撃ち。
成功例 2 件（RedPen の「の」連鎖、textlint-ja の 4 漢字工程名詞連結）はどちらも
発火条件を極端に狭く絞り、「語の正誤ではなくレビューで読み直したほうがよい構造の報告」と
自己定義している。この repo の [ja-no-nominalization.js](./prototypes/ja-no-nominalization.js)
（誤検知 1.3% 実測）も同じ型で、調査で組んだ検出器（1.84%、精度およそ 5 割）も同水準。

### 規範設計に効く 2 つの制約

制限日本語の系譜が一貫して報告しているトレードオフがある。
宮田・影浦・Hartley (2012) の 20 規則の評価で、20 規則中 12 規則が日本語の可読性を低下させ、
うち 6 規則は 60% 以上の文で低下した。
機械翻訳を通しやすくする規則の多くは日本語としての読みやすさを犠牲にする。
可読性側の実測がある規則（主語の明示、冗長語の削除）に絞るのが安全。

「係り受け距離を短くせよ」を可読性の根拠に置くのは誤り。
浅原 (2018, PACLIC 32) の BCCWJ-EyeTrack（24 名の視線計測）で、日本語では
その文節に係ってくる依存要素が多いほど速く読まれる（anti-locality）。
Gibson の DLT が予測する locality effect とは逆向き。
距離の規範は読み時間ではなく曖昧性に根拠を置く必要がある。

## 英語ガイドから輸入した規範では拾えない型

Microsoft Japanese Localization Style Guide が
"Syntax: This section does not apply to Japanese." /
"Word Order: This section does not apply to Japanese." と明記している。
全言語共通テンプレートの統語・語順の枠を日本語では意図的に空欄にしている。

| 日本語の型 | 英語ガイドの条項 |
| --- | --- |
| 主題「は」のスコープ | なし。英語は主題を形態標示しない |
| 格助詞の省略 | なし。英語は格を語順で標示する |
| ゼロ代名詞 | 部分的。英語は代名詞の形式が残り数・性が手がかりになる |
| 内の関係 / 外の関係 | なし。英語は関係節と同格節が別構文 |
| 属格主語（ガノ交替） | なし |
| 総記 / 中立叙述の「が」 | なし。英語は強勢・分裂文で解消 |
| 「られる」4 用法 | 部分的 |
| 「自分」 | なし。英語は his/her で解消 |
| 間接受身・使役の 4 通り・授受 | なし |
| 引用節の始端 | なし。英語は引用符・語順倒置・that で完全に決まる |
| 同綴異音多義 | なし。漢字仮名交じり表記に固有 |
| 前置修飾語の係り先 | 現象は同型だが、英語には後置による非曖昧な書き分けがある |
| garden path | あるが向きが逆 |
| 並列 | 同型だが探索方向が鏡像。日本語は連用中止法が加わる |

日本語で多義が集中する構造的理由は 4 点。
(1) 主要部後置でスコープの右端が主要部まで確定しない、
(2) 修飾語が常に前置で後置による非曖昧な言い換えがない、
(3) 名詞・接辞の連鎖に助詞という標示がない、
(4) 項の省略が自由で格助詞も落とせる。

## 未確認・確度の注記

### 原典が未取得

- 本多勝一『日本語の作文技術』。修飾の 4 原則とテンの二大原則は独立した紹介 4 件の一致で確認したが、
  原則同士が競合したときの優先などの但し書きは未確認。一般書で言語学の査読を経ていない
- 『現代日本語文法』全 7 巻（巻構成・章立てのみ公式書誌で確認）。否定のスコープの正典は第 3 巻第 7 部 第 3 章
- Kess &amp; 西光 (1989)『Linguistic Ambiguity in Natural Language: English and Japanese』くろしお出版。
  英日対照の唯一の専著で入手の優先度は最高
- 矢澤真人 (1987/88/89)『国語国文論集』16/17/18。副詞の係り先の唯一の学術的裏付け候補で、
  ここが調査最大の欠落
- 記者ハンドブック第 14 版、TC 協会『日本語スタイルガイド』第 3 版、木下是雄『理科系の作文技術』

### 文献が存在しなかった

- 接辞のスコープ多義の査読論文（CiNii の複数クエリで 0 件）
- 「の」連鎖の入れ子構造の多義を主題にした日本語学の一次文献
- 体言止め・見出し文の構造的多義（文体論の文献のみ）
- 日本語の懸垂修飾（CiNii 0 件）。日本語はテ形節・連用中止節の主語不一致が常態で
  主語省略が既定のため、違反カテゴリとして成立しない
- 並列・連体修飾・否定スコープの型ごとの誤訳率を実測した論文

### 通説だが支持されていない

- 「ヲ使役 = 強制 / ニ使役 = 許可」
- 「ながら = A 類、ので = B 類」型の接続助詞と節の類の固定対応
- 「美しい水車小屋の娘」は Schubert の邦題由来で学術的議論を確認できず。
  規範に載せるなら学術例（「彼は美しい彼女の歌声を聞いた」等）に差し替える
- 「ピリオド越え」は学術文献での使用を確認できず。三上の原文「勢力を文末まで及ぼす」を使う
