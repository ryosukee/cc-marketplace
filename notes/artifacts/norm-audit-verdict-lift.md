# 処遇判定: 既存なし 85 件（段階 1-2）

既存規範に同趣旨が無い条項。引き上げ候補。
語彙は `norm-audit-raw/verdict-schema.md` に従う。

## 判定の規則

突合が付けた移設先の候補は、`確認` と `subagent` と `その他` を含んでいる。
これらは `verdict-schema.md` の層の語彙に無いので、次で読み替える。

| 突合の候補 | 層の語彙 | 理由 |
| --- | --- | --- |
| `core` / `判断` / `参照` / `読み物` | そのまま | |
| `確認` | `plugin`（html-communication） | 確認・質問の規範は ask-with-choices が廃止されるので HC が実体になる |
| `subagent` | `維持` の対象 | `rules/subagent-delegation.md` は今回の監査の対象外（後続タスク #7）。移設先が監査されていない層なので、いま動かさない |
| `その他` | 個別に判定 | 下記 |
| `据え置き` | `維持` | |

`その他` に落ちた条項の大半は、調査手段の選択・調査の網羅性・成果物と規約の照合で、
**執筆規範ではない**。impl-spec の作業手順に属する。移設先へ同行させる。

| ID | 内容 | 引き上げ先 |
| --- | --- | --- |

| IS34 | 調査で判明したことは質問しない。自明に決まる判断は報告にとどめる | `plugin`（HC） |
