# 復元した確認フォーム

削除済みの確認フォーム 10 ページを transcript から復元したもの。

## 復元した理由

台帳 [norm-refit 台帳](../../norm-refit.md) は確定の出典をページのファイル名で書いていたため、
根拠がページの生存に依存していた。ページは html-communication skill の掃除規定
（完了は直近 10 件まで、古い順に削除）で消える。

実測（2026-08-19）で、台帳の出典 42 件のうち 23 件は参照先が消えていた。
そのうち入口 rule の承認済み実文ドラフト（f007 の回で決まったもの）は、
台帳に「ユーザー承認済み」とだけ書かれていて実文が無く、一度は復元不能と判断した。

## 復元の方法

`~/.claude/projects/<project>/*.jsonl` に Write / Edit の入力がそのまま残る。
これを時刻順に適用し直すとページが戻る。ページによっては python の heredoc で
推敲されており、その場合は HOME を差し替えた砂場で Bash を再実行した。

適用漏れは全 10 ページで 0 件。不一致が出た 4 件はいずれも当時の実行でも
`is_error` で失敗していた Edit で、原本にも反映されていないことを
transcript の tool_result で確認済み。
