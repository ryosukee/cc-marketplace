# IS 汎用条項の既存規範との突合

`is.md` の 性質=汎用 182 件から、重複グループの判定で既に扱った 31 件を除いた **151 件**が対象。
依頼文の除外リスト 37 ID のうち 6 件（IS70 / IS90 / IS141 / IS143 / IS163 / IS283）は
`is.md` 側で 性質=汎用 ではないため、除外しても件数が減らない。差の 3 件（依頼文の目安 148 → 実測 151）はこれで説明できる。

処遇は判定しない。分類と引き上げ先候補の提示までが範囲。

## 突合の方法

突合先 29 ファイル（`rules/` 直下 10 / `rules/references/notes-format.md` /
japanese-text-writing の SKILL.md + references 5 / ask-with-choices SKILL.md /
html-communication SKILL.md + references/review-norms.md /
session の skills 5 本 + handover-reviewer.md + references 2 本 + README.md）を全文読み、
条項単位で突合した。`既存あり` と `部分的` の引用は、読んだ原文からの逐語転記。

3 skill 間で同趣旨の条項は代表 1 件で判定し、`同一条項の他 ID` に残りを併記した。
原文が完全一致しないもの（「ドキュメント規約 / 設計規約 / テスト規約」のような語の差だけのもの）も
同じ扱いにし、差分は代表エントリの中に注記した。
