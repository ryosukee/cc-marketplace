# norm-refit の PR レビューの文レベル指摘 事例集

norm-refit 段階 4 群 3「日本語の構造的曖昧性を規範と検知に落とす」の着手時に、設計の入力として参照する。
出典は norm-refit の PR（PR #6 <https://github.com/ryosukee/cc-marketplace/pull/6> 以降の全 PR）のレビューと、その対応 commit・セルフレビュー（review agent）・横展開スイープ（例: `46ac934`・`cab2ce6`）。norm-refit の完了で蓄積を終える。
文レベル（語順・格の位置・係り受け・助詞・曖昧な構造・表記）の指摘だけを集め、構成・配置・規範の内容の是非は含めない。各事例の実文は逐語で、要約・言い換えをしない。

記法: 「before」は指摘された文、「after」は直した文。「未対応」は PR head `cab2ce6`（2026-08-25 時点）に before の文が残っていることを示す。
出典の `path:line` は、コメントなら GitHub 上の `original_line`、commit なら diff の行を指す。
出所: 各事例に「出所: 人間のレビュー」「出所: review agent」「出所: Claude の横展開スイープ」のいずれかを付ける。信頼度が違う（人間の指摘が高い）ので、混ぜて数えない。
