# 処遇判定: 重複グループ外（機械的に決まる分）

重複グループ 47 の判定で扱わなかった 1028 条項のうち、性質と略号だけで処遇が決まる 657 件。
残る 371 件は 1 件ずつ吟味する（別ファイル）。

語彙は `norm-audit-raw/verdict-schema.md` に従う。

## 判定の根拠

3 つとも、条項の中身を読まずに決めてよい。所属と性質だけで行き先が一意に決まるため。

- **IS × 媒体固有**: impl-spec は norm-refit 完了後に product-workflow へ移設される
  （idea-hub Q43 / Q109 / Q110、実装計画 PR 8）。媒体固有の条項は移設先で意味を保つ
- **HC / GP / SS / FN × 媒体固有**: HTML ページ・PR 本文・引き継ぎ資料でしか意味がなく、
  cc-marketplace に残る plugin なので現在地が正しい
- **AQ 全件**: ask-with-choices skill 自体の廃止が確定済み（台帳 L963-964）。
  条項の中身に関わらず消える。振り分け基準は HC が持つ

## 例外の申し送り

この 657 件は中身を読んでいない。次のどちらかに当たるものが紛れていたら、吟味側へ移す。

- 性質の判定が誤っている（汎用なのに媒体固有と付けられた）
- 移設・廃止の前提が変わった（impl-spec の移設中止、AQ 廃止の撤回）

判定基準: 実装で条項を触るとき、原文を読んで違和感があれば止めて吟味側へ回す。
