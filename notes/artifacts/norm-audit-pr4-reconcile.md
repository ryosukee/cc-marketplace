突合した。対象は判定で「詳細規範 4 ファイル（core / 判断 / 参照 / 読み物）または入口 rule へ行く」
とされた条項 252 件。採否は決めない。

## 判断材料

### 一致の偏り

一致 159 件はファイルによって密度が違う。

- `narrative-docs.md`: 49 件中 48 件が一致。PR は解説（EW）と読み物（NW）の 2 ファイルを 1 本へ畳み、
  節を「解説・読み物に共通」と「読み物だけ」へ切り分けている。判定が求めた統合 4 組のうち
  EW1 + NW1 + NW2、EW2 + EW3 + NW18、EW9 + EW10 + NW5 + NW6 の 3 組が実施済み
- `reference-docs.md`: 24 件中 17 件が一致。RD の元ファイルからの移動は判定どおり
  （RD4 を core へ、表の 2 件を外へ）
- `decision-docs.md`: 46 件中 29 件が一致。DD の元ファイル分はほぼ判定どおりだが、
  論文ファイルを末尾の追加適用節へ畳んだ結果、core へ上げるべき 9 件が論文節に残った
- `core.md`: 128 件中 62 件が一致（48%）。元の SKILL.md にあった SK / JR 系はほぼ移っているが、
  他ファイル（MF・HC・SS・GP・FN・IS）から core へ引き上げる分が 1 件も入っていない

### 不足 93 件の性質

不足の 93 件は、PR ブランチが触っていないファイルからの引き上げが 72 件を占める。

| 出どころ | 件数 | PR が該当ファイルを触っているか |
| --- | ---: | --- |
| `rules/markdown-formatting.md`（MF） | 20 | 触っている（参照文の書き換えのみ。条項の移動なし） |
| impl-spec（IS） | 8 | 触っていない |
| session / claude-user-communication / github-pr（SS・HC・GP・FN） | 27 | 触っていない |
| 判断保留 B 群（GP・HC・FN） | 17 | 触っていない |
| 詳細規範 4 ファイル内の置き場違い | 20 | 触っている |
| 入口 rule（UC15・UC16） | 2 | 触っている |

前 4 行の 72 件は、PR を活かす場合も作り直す場合も、条項の原文を別ファイルから引いて
一般化する作業が新規に発生する。工数はどちらの経路でも変わらない。

後 2 行の 22 件は、PR の実文の中で位置を動かす作業になる。うち 20 件は core と
`decision-docs.md` / `reference-docs.md` の間の移動で、行単位の切り貼りで済む。

### 過剰 29 件の性質

| 性質 | 件数 | 直し方 |
| --- | ---: | --- |
| 判定が別ファイルへ移すと定めているのに元の場所に残っている | 16 | 移動（不足側と同じ操作） |
| 段階 2 の決定（2026-08-20）に反する | 4 | 削除・条件付けの字句修正 |
| 判定が削除と定めているのに残っている | 2 | 削除 |

段階 2 の決定に反する 4 件はすべて字句単位で、`core.md` L89 と `decision-docs.md` L20 から
「読み方」を消し、`core.md` L154 から「決め手の観点を本文で名指しする」を消し、
同 L153 の表の補足に媒体条件を付ける操作になる。

「監査の対象外だった実文」5 件は、PR が独自に書き足した節（「何を書き、何を書かないか」
「名詞構文」「経緯・出典注記の抑制」ほか）で、監査は main HEAD から条項を抽出したため
判定を持たない。作り直す場合はこの 5 件の文面が失われる。

### 作業量の見積もり

PR を活かす経路の残作業。

- 不足 93 件の追加。うち 72 件は別ファイルからの引き上げと一般化（新規執筆）、
  21 件は PR 内での移動（機械的）
- 過剰 29 件の処理。うち 16 件は不足側の移動と同じ操作なので重複し、実質 13 件
- 実質の残作業は「新規執筆 72 件」＋「PR 内の移動 21 件」＋「削除・字句修正 13 件」

作り直す経路の残作業。

- 判定対象 252 件すべての執筆。ただし一致している 159 件は PR の実文をそのまま写せる
- 加えて、PR が独自に書いた 5 件の実文（監査対象外）を写すか捨てるかの判断
- ファイル構造（frontmatter の `paths` による常時ロード除外、4 ファイル構成、
  リンクの張り替え、plugin 解体、`.claude/rules/coding.md` と `CLAUDE.md` と `README.md` の追随）は
  PR が済ませており、この分は経路によらず再利用できる

差は「一致 159 件を写す手間」対「過剰 13 件を消す手間 + PR 内の移動 21 件」になる。
