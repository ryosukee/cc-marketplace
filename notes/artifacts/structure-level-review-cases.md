# レビューの構造レベル指摘 事例集

レビューで受けた構造の観点の指摘を集める。対象は、何をどこに置くか、何を書いて何を落とすか、
表と地の文の役割分担、参照の張り方。規範の内容の是非は含めない。

文レベル（語順・格の位置・係り受け・助詞・曖昧な構造・表記）は
[norm-refit の PR レビューの文レベル指摘 事例集](./sentence-level-review-cases.md) が扱い、こちらでは扱わない。
1 つの指摘が両方に当たるときは、当たる部分をそれぞれの事例集に分けて書き、互いの事例番号で参照する。

記法: 「before」は指摘された記述、「after」は直した記述。各事例の実文は逐語で、要約・言い換えをしない。
引用の中のリンク記法は、指す先がこの repo に無く markdownlint の link-fragments に掛かるため、インラインコードで囲んで文字だけを残す。
出所: 各事例に「出所: 人間のレビュー（repo 名）」「出所: review agent」のいずれかを付ける。信頼度が違うので混ぜて数えない。
収集元の repo: cc-marketplace 以外から来た事例は、節の見出しの先頭に `[repo 名]` を付け、出典にその repo の PR とレビューの場所を書く。
型の名前は指摘を束ねるためのもので、規則として読まない。指摘の実文が述べていない一般則を型の名前に書かない。
型: 1 つの事例が複数の型に当たることがある。節の見出しはその事例を置いた型を示し、他にも当たる型があるときは事例の末尾に「型: 1, 3」の形で当たる型をすべて列挙する（節の型も含める）。件数は延べ（型ごとの合計）と実数（事例の数）を分けて出す。
