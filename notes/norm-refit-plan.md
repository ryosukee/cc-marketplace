## 段階 1 判定を閉じる

残る 365 条項に処遇を付ける。突合は完了しており、材料は揃っている。

作業は 4 つ。すべて機械的で、新しい判断は生じない。

### 1-1 既存ありの 70 件を閉じる

`is-generic-screening.md` と `plugin-generic-screening.md` の `既存あり` 分類。
同趣旨が既存規範にあるので、処遇は次で一意に決まる。

- 実体が詳細規範側にある → 条項は `削除`（plugin から消す）。ただし plugin が
  自己完結原則で持つ必要があるものは `維持`
- 実体が plugin 側にしかない → その plugin が実体。`維持`
- 実体が impl-spec 側にある → `移設先` へ同行

判定基準: その plugin が単独でインストールされたとき、この条項が無いと壊れるか。
壊れるなら `維持`、壊れないなら `削除`。

### 1-2 既存なしの 85 件を閉じる

引き上げ候補。突合が `移設先の候補` を付けているので、それを検証して確定させる。

- 候補が `core` / `判断` / `参照` / `読み物` → `移設`。一般化の要否が付いているものは
  文案を実装明細へ書く
- 候補が `据え置き` → `維持`
- impl-spec 由来のものは、引き上げる（cc-marketplace に残す）か
  同行させる（`移設先`）かを 1 件ずつ決める。**これが段階 1 の主作業**

判定基準: 足りない部分を既存の条項へ足したとき、既存の条項が読めなくなるか。

### 2-2 条件ロードの穴を塞ぐ設計

`rules/markdown-formatting.md` は `paths: **/*.md` の条件ロードで、
markdown ファイルを扱うときしか読み込まれない。PR 本文・HTML ページ本文・確認フォーム本文・
ターミナル返答の 4 媒体に届かない。

github-pr はこれを自覚してトンマナ規範を持ち直している
（`generate-body.md:63`「PR 本文は `.md` ファイルではないため、Markdown 向けの整形ルールが
自動適用されない」）。

該当する条項は 15 件（C 群の `記法一般` 9 + `混在` 6）と、汎用でありながら実体が
条件ロードの下にある 5 件（MF13〜MF16 の和欧混植、HC159）。

穴を塞ぐ手段の候補は次の 3 つ。どれを採るかで、GP / HC のトンマナ再実装を削れるかが決まる。

- `paths` を広げる。ただし常時ロードに近づき、総量が増える
- 記法規範を媒体非依存の分と markdown 固有の分に割り、前者を詳細規範へ移す
- 各 plugin が持ち直す現状を追認し、条項として正当化する

**この設計が決まるまで、GP / HC のトンマナ条項は `保留` のまま実装しない。**

候補は 2 つ足りていなかった。生成物を検査する側に判定を足す案が 2 通りある。

- 機械検査で事後に拾う（markdownlint plugin・page-reviewer の機械検査に足す）。
  読み込みに依存しないが、生成時には効かず、意味判断が要る条項を拾えない
- review agent で事後に拾う。意味判断が要る条項も拾えるが、agent の起動コストがかかる

**20 件のうち 6 件は条項を割る必要がある**（MF5 / MF9 / MF10 / MF21 / MF32 / MF44）。
C 群の判定で「混在」とされたもので、1 条項の中に記法一般の核と markdown 固有の値が同居している。
B 群の分割 10 件と同じ扱い（汎用の核を移設、媒体固有の値を維持）にする。
単純に 20 件をまるごと移す形にはならない。

この項目は `ccm-f030` の設問 6 として出した。**T4 へ送らない。**

## PR の出し方

**適用範囲は norm-refit の段階 3・4・5 と、後続タスク。**

実装は必ず PR にする。main へ直接入れない。PR に notes を混ぜない（レビュースコープが膨れる）。
notes の更新は main へ直接入れる。

PR を出す前に、必ずセルフレビューを通す。順序は次のとおりで、飛ばさない。

1. 実装して、機械で確かめられるもの（lint・リンク解決・壊れた参照・実際に発火させる検証）を通す
2. review agent を起動してセルフレビューする。観点は、規範の欠落と実文の改変
3. 指摘を直す
4. PR を出す

レビューは PR ごとにゼロベースで行い、前の PR のレビュー結果を前提にしない。
